Changes and individual implementation commits

f3d8f83: World-clock text fits its 118-pixel region, and the clear region covers
          the full font height. Previously a 26-pixel clear could leave fragments
          of 48-pixel glyphs and oversized time text could overflow the region.
48ccc84: Focus, world-clock and event text share the existing 1 bpp clock buffer.
          A cropped push sends complete text without first blanking the screen.
          Focus duration labels are drawn with the static page instead of every
          countdown update. No additional framebuffer was allocated.
e334e1f: Delayed reset responses preserve newer dashboard/feed edits.
1734123: Refresh responses preserve local edits made before or during the request,
          and do not cancel pending previews. Clean forms still hydrate normally.
6206088: The login dialog keeps keyboard focus inside visible controls, makes the
          background inert, and returns focus to the current tab after login.
          Page chips show keyboard focus; auth/sync messages expose live semantics.
ef31678: Failed EEPROM settings commits return failure, keep the previous saved
          snapshot, and restore the EEPROM RAM buffer so a later counter commit
          does not silently persist the failed candidate. API saves return an
          error rather than claiming success. This cannot restore a flash sector
          already erased by a failing physical write; power-loss safety remains
          a device-level limitation of EEPROM emulation.
a6e3e54: File upload controls and long device names no longer force horizontal
          overflow on small screens. Native browser checks reproduce both cases.
1c14695: mDNS/OTA can initialize at realistic free-heap levels, while retaining an
          8 KB low-heap gate and the existing retry/warmup behavior. The previous
          28 KB gate was close to the build's entire available DRAM heap.
eaf5215: The roughly 1.7 KB display buffer can activate with 10 KB free, leaving
          at least 8 KB headroom. Previously its 30 KB gate exceeded the maximum
          possible primary heap in this build. TLS still suspends this buffer.
e621e44: Formatted/static diagnostics are stored in flash, recovering 860 bytes
          of measured static RAM. Log messages and ring-buffer behavior remain.
f4d32ab: Focus redraw hashes track visible duration text and pixel progress,
          avoiding updates when a long timer's displayed minute is unchanged.
          The progress calculation is shared by rendering and invalidation.
7ed9a21: Static API error/feedback strings move to flash, recovering another
          1,664 bytes of measured static RAM before compression integration.
d927913: PlatformIO generates deterministic gzip pages from editable webui.h.
          The actual root and OTA handlers send flash bytes with explicit lengths
          and Content-Encoding. The raw pages are absent from linked firmware.
