Device UI redesign — 2026-10-14

User request

Redesign the small 240x240 device screen for larger, more legible information,
especially market percentage changes and temperature. Replace the intrusive
section/IP top bar with a cleaner layout while retaining both pieces of context.
Use the available screen area and reduce decorative clutter.

Implemented source: e47c966

All nine dashboard layouts use the full background and wider content area.
Section name and optional IPv4 address move to a 16-pixel footer. Market,
Home Assistant and world-clock sections show one item at a time, with a 1/N
position indicator. Short button presses and automatic rotation visit every
available item before leaving a section; the existing interval applies per item.
Configuration versions and persisted settings do not change.

For typical data the market percentage is 52 pixels high (previously 8),
main weather temperature 78 (previously 26), and clock temperature 52. Home
Assistant values and focus/event timers use enlarged text; units, headings,
quotes and status lines also have clearer hierarchy. Oversized text uses bounded
fitting/wrapping and explicit ellipsis. Static labels are at least 16 pixels.
High/low/rain remain together on Weather; Clock shows temperature and condition.

Dynamic text reuses the existing 216x64 one-bit drawing buffer (about 1.7 KB).
Scaled text resets to size 1 after each draw. Static hashes track the visible
market/entity/world item, so an update to an unseen item does not clear its card.
Full page changes retain the existing transition behavior. The low-memory direct
drawing fallback remains available; no whole-screen framebuffer is introduced.

The web control labels now say Footer IP and Seconds per screen, with a note
about the item sequence. README describes the updated button and rotation behavior.

Physical assessment

Native startup and pixel-accurate previews prove implementation and layout bounds,
not readability for every person at a distance. The user was asked to assess the
market percentage, temperature and footer from their usual viewing position.
The user subsequently confirmed that the flashed layout feels good and requested
a final review and more professional device palettes. Metadata remains smaller
than the primary values because the panel is physically small; no universal distance guarantee
or claim of physically verified flicker elimination is made.
